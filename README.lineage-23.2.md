# Common vendor integration for LineageOS 23.2

The local branch starts at the supplied `lineage-22.2` tip (`0f76c69`). Existing
proprietary files and fixups are retained; no proprietary binary was rewritten.
Android.bp and sm6150-common-vendor.mk are regenerated by the platform's current
extract-utils through `device/samsung/a70q/extract-files.py --regenerate_makefiles`.

The current generator uses path-derived RFSA/DSP module names. It also restores
`vendor.samsung.hardware.radio@2.0` / `@2.1` dependencies of libril, provided by
`hardware/samsung`, and removes the manual libril ELF-check exemption. Existing
per-blob exceptions in proprietary-files.txt remain; regeneration is not proof
that all ELF checks or runtime symbol resolution pass.

Keep the existing RIL/crypto/Widevine fixups in sm6150-common/extract-files.py as
the source of truth. Future ABI fixes must be added there and regenerated; do
not make unrepeatable Android.bp or binary edits. Dependencies include the sm8150
Qualcomm family, WLAN, dataservices, Samsung interfaces and the Lineage compat
libraries (including libcrypto-v33 and protobuf vendorcompat).

The build/runtime validation boundary is documented in
`device/samsung/a70q/compatibility/validation.md`. No boot or hardware claim is made.
